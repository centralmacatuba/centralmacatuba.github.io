Bem-vindo à API Pública

Este repositório contém o site oficial e a documentação técnica da Central Macatuba. A API Pública oferece acesso programático a dados abertos e informações em tempo real sobre o município, seguindo uma arquitetura modular e orientada a serviços.

URL Base da API: https://publica.api.centralmacatuba.eu.org/api
